# 一次 FDE 实践，看见 UI（人机交互）革命

> FDE（前线部署工程师）是深入客户业务场景，负责将技术产品集成、部署并解决实际问题的工程师。  
> UI 是计算机提供给人使用的一套“操作界面”，是人与计算机沟通、交互的桥梁。

## 实践场景

一家网吧企业有四个老板，管理 30 个店长，几百号员工；  
企业靠行业内专用的后台系统管理客户、设备、仓库、收银；使用企业微信进行组织沟通；  
后台系统功能很丰富，也很复杂，老板和店长基本不用，只通过小程序看两三个核心指标，如营业额、上座率；  
一些为提升服务质量的企业内部流程数据，则由专门的员工通过 Excel 表格进行管理。

这应该是大多数实体行业的共同现象，买一套互联网公司开发的专用系统，配几个懂电脑的员工来使用系统；  
基本流程都能正常运行，大多数功能是用不着的，不能满足的需求就退化成 Excel 管理。

总结来说，就是凑合着用，就像穿着一套不合身的衣服。

## 现在的系统

以上人们的合作/工作模式，就是互联网所塑造的；  
计算机系统的本质是“输入 - 处理 - 输出”，它要求精确的输入，提供固定标准化的输出；  
将人与人之间的协作流程，抽象为表单与流程，替代传统的纸张、打字机、电话。

这其实是违反人们日常的语言交流模式的，即使面向普通大众的 C 端 APP，费尽心计去简化 UI，仍然会将大部分老人拒之门外。

系统不断排斥两三个用户的“奇怪”诉求，因为定制意味着持久的成本；  
系统不断吸收七八个相似的用户需求，标准化为通用流程，制作成表单与页面，堆叠到系统之中；

因此系统复杂度不可避免地增加，直到系统的后台界面演变成复杂的迷宫，充满路障与陷阱。

系统真正的用户不再使用它，而是配一个专门的员工代替自己操作这复杂的系统。  
最典型的是，窗口/柜台上操作电脑的工作人员，代替办事客户操作系统。

当一个实习生在电话中咨询前辈，如何在后台系统中完成某个任务，前辈说：  
先这样，再这样，然后这样，最后再这样。

最终的结果：要么提示“您无权访问页面”，要么在弹窗中点击“确认”按钮后引爆系统。

## UI 革命

UI 革命的目标，是将人机交流回归到人与人之间自然语言交流的状态。

一个聊天界面，替代整个系统的导航、页面、表单，Agent 替代与系统对接的操作员。

聊天界面是极度简化、又极具包容性的 UI 设计，它是人与人之间用自然语言交流这一模式的呈现。  
以前复杂的表单页面，目的是向系统输入精确、规范的信息；而 AI 最擅长的，就是从模糊的语言中提取出精确信息输入系统，然后总结或解释系统输出的复杂信息。

因此借助 AI 对话框，人机交互可以回归到自然交流状态。

编程是个技术活，程序员使用的编程工具 —— IDE 是复杂 UI 的典型案例，由于 AI 技术的进步，当前编程工作基本可以在一个极度简化的聊天界面完成。

回到最开始提到的网吧 FDE 项目，成果是：

- 老板、店长可以随时在企业微信中 @AI助理，了解门店的经营状况、竞对门店数据，并给出分析建议；
- AI 会学习业务知识，适应用户的沟通风格，记忆用户的习惯；
- 用手机中的聊天窗口 + AI 助理，替代了 PC 上的后台系统。

实现原理：

- AI 助理最终会将用户请求分解成对后台系统接口的查询；
- AI 将 Excel 文档当作数据库，实现企业内部的定制化流程。

这样就以极低的成本实现了企业内部流程提效，也不会破坏原有的使用习惯。

## 对话框能承载复杂信息吗

有人会担心如此简单的界面是否能正在复杂信息，毕竟某些场景很难用语言精确描述，系统输出高密度信息也难以用文字表达，或因内容太长不方便阅读。

现阶段确实还不够，因为当前对话框是为人与人之间的交流而设计的，但不可低估对话框 UI 的潜力，升级当前对话框的表达能力并不困难。

当前不少 IM（即时通信）软件的消息气泡已经支持 Markdown 渲染，也就是支持了重点文本凸显、数据表格、图文混排；  
相对纯文本，可阅读性有所增加；  
再升级为 HTML 渲染（必然趋势），即可补全对话框的信息表达能力。

当前已经可以在 GPT/Codex 桌面版中，看到 AI 会根据上下生成表单让用户选择方案做决策，会联网抓取或生成图片到输出信息，来增强可视化表达。

既然都用到了 HTML 技术，那跟之前的页面设计（UI）有什么不同？  
关键区别在于，AI 输出到对话框的 HTML 内容针对个人的，之前的系统虽然采用 HTML 技术，但它是固定的、为所有人预制的页面。

AI 会为每个人生成专属页面，收集必要的精确信息、做定制的可视化表达；  
这样才能在“信息的复杂性 - UI 的简单性”之间取得平衡，就像完全为个人定制的衣服鞋子。

## 新时代

传统互联网系统的“精确性、复杂性”，导致系统需要配备专业的操作员；  
新时代引入 AI 来降低门槛，适配更多的用户，同时引入了多样性、碎片化、模糊性。

新的 UI 会产生新的程序范式、新的系统架构，也会引入新的问题。

我们的程序代码应该如何组织，系统架构应该如何设计？

这也是 FDE 流行的原因，现在需要前线程序员去满足客户的定制需求，解决新时代的问题。
